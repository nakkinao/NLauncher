# NLauncher

ページ・グループ・ウィジェットを自由に使える Android ホームアプリ（ランチャー）です。

## ダウンロード

最新版 APK: https://github.com/nakkinao/NLauncher/releases/latest/download/NLauncher.apk

インストール後、「設定 → アプリ → デフォルトのアプリ → ホームアプリ」で NLauncher を選択してください。
（Android 8.0 以上）

## 機能

- **ページ単位の移動** — 左右スワイプでページ送り（スナップ）。ドットをタップしてジャンプ。
  ページの追加・削除・並べ替え（左へ/右へ移動）が可能。ドラッグ中に画面端で止めると隣のページへ移動し、最後のページの右端では新しいページが作られます。
- **グループ分け** — アプリを別のアプリの上にドロップするとグループ化。グループの上にドロップすると追加。
  ホーム長押し →「グループを作成」、ドロワーのアプリ長押し →「グループに追加」からも作れます。グループ内は長押しドラッグで並べ替え。
- **グループのアイコン作成** — 「アプリを並べる / 文字・絵文字 / 画像（ギャラリーから）」の3スタイル、形（丸・角丸・スクワークル・四角）、背景色・透明度、文字色を選んで作成。
- **グループでスクロール** — グループを開くと中身を縦スクロール。さらに「ホームでスクロール表示（パネル）」にすると、ホーム画面上でグループの中身を縦/横にスクロールでき、サイズも自由に変更できます。
- **ウィジェット無制限** — 端末にあるすべてのウィジェットを追加可能（設定画面付きのウィジェット、仕事用プロファイルにも対応）。数の制限なし、1×1 からページ全体まで自由にサイズ変更、ページ間の移動も可。

## 操作

| 操作 | 動作 |
| --- | --- |
| ホームの空き部分を長押し | メニュー（ウィジェット追加・グループ作成・ページ操作・壁紙・設定） |
| アイコン/ウィジェットを長押し → ドラッグ | 移動（画面端で別ページへ） |
| アイコン/ウィジェットを長押し → 離す | そのアイテムのメニュー（サイズ変更・削除など） |
| 上スワイプ / 下の ︿ | アプリ一覧（検索付き） |
| 下スワイプ | 通知パネル |

## ビルド

```
./gradlew assembleRelease
```

GitHub Actions が push ごとに APK をビルドします。`main` への push、`v*` タグ、または手動実行で GitHub Release が作成されます。

### 署名について

リポジトリ同梱の `keystore/nlauncher-public.jks` は、ビルド間で署名を一定にするための**公開用キー**です（パスワードも公開）。
本番配布用には独自のキーストアを作り、リポジトリの Secrets に `NL_KEYSTORE_BASE64` / `NL_KEYSTORE_PASSWORD` / `NL_KEY_ALIAS` / `NL_KEY_PASSWORD` を設定すると、そちらで署名されます。
